# 詞彙教室（離線版）

一個純前端、可離線使用的 PWA 單字複習 App。內建兩套字庫：

- 國中會考2000單字
- 高中英文參考詞彙（111學年度起）

合計 **7944 字**。所有學習進度（熟練度、複習排程）都存在**使用者自己裝置的瀏覽器 IndexedDB** 裡，每台裝置各自獨立、**沒有帳號、沒有伺服器**，跟後端 `web/` 版是完全分開的兩套系統。

---

## 給開發者：重新產生字庫 bundle

字庫資料是從 `my_vocab.db` 匯出成 `standalone/data/vocab-bundle.json`（App 第一次啟動時會讀取這個檔案，灌進使用者的 IndexedDB）。若 `my_vocab.db` 的內容有更新，需要重新匯出：

```bash
python tools/export_bundle.py <my_vocab.db 的路徑> standalone/data/vocab-bundle.json
```

只會匯出上面兩個來源的資料（其他來源，例如手動新增的單字，不會被打包進去），執行完會印出統計，預期是兩個來源、共 7944 筆。

> 注意：這個腳本只是「重新產生資料檔」，不會影響任何人已經在用的進度——已安裝的 App 只有在**第一次啟動、IndexedDB 是空的**時候才會載入 bundle；已經在用的裝置不會被新 bundle 覆蓋。

## 給開發者：部署到 GitHub Pages

把 `standalone/` 目錄的內容，當成一個純靜態網站發佈即可，例如：

- 推到專案的 `gh-pages` 分支，把 `standalone/` 內容放在分支根目錄；或
- 在 GitHub repo 的 Settings → Pages，把來源目錄指到 `standalone/`（依 repo 設定選擇分支或路徑）。

也可以改用 Cloudflare Pages、Netlify 等靜態託管服務，只要把 `standalone/` 當成部署根目錄即可。

**⚠️ 每次重新部署且改動了任何 standalone 檔案時，必須把 `standalone/sw.js` 裡的 `CACHE` 常數版本號 +1**（例如 `vocab-classroom-v1` → `-v2`），否則已經安裝的裝置會停在舊版、拿不到更新。

**⚠️ 網址一旦給朋友用了，之後就不要換。**
這個 App 沒有帳號、沒有雲端同步，朋友的所有進度都只綁定在「他瀏覽器裡對應這個網址的 IndexedDB」。換一個新網址（換網域、換路徑、換託管服務）等於是給他一個**全新的空 App**，原本存的進度不會跟著搬過去，等於歸零。部署好之後，這個網址就固定下來，不要再改。

## 給朋友：怎麼安裝到手機

App 第一次打開時需要連網（下載 App 本身跟字庫，大約數 MB），**之後就可以完全離線使用**，不用一直連網路。

### Android（Chrome）

1. 用 Chrome 打開這個網址。
2. 通常畫面上會自動跳出「安裝應用程式」的提示，點下去就好。
3. 如果沒有自動跳出，點右上角選單（⋮），選「安裝應用程式」或「加到主畫面」。

### iPhone / iPad（Safari）

1. 用 Safari 打開這個網址（**要用 Safari**，其他瀏覽器沒有這個功能）。
2. 點下方（或上方）的「分享」按鈕（方框加箭頭的圖示）。
3. 選「加入主畫面」。

安裝完之後，手機桌面上會出現一個「詞彙教室」的圖示，點它開起來就跟一般 App 一樣，全螢幕、沒有網址列。

> 這不是從 App Store／Google Play 下載的正式 App，是「加到主畫面」這種輕量安裝方式，但用起來跟一般 App 沒什麼差別。

## 給朋友：資料存在哪裡、怎麼備份（重要）

你的複習進度（哪些字已經記熟、哪些還不熟、下次什麼時候要複習）**只存在你自己這台裝置的瀏覽器裡**，不會傳到任何伺服器，換一台手機或電腦就等於是重新開始（除非你有備份，見下面）。

而且瀏覽器本身有時候會自動清掉網站的本機資料，尤其是：

- **iPhone / iPad（Safari）特別要注意**：如果一個網站超過大約 7 天沒有被打開，iOS 系統可能會自動把它的本機資料清掉，你的進度就會不見。

所以請**養成定期備份的習慣**：

1. 打開 App，找到「⬇️ 匯出備份」按鈕，點一下，會下載一個 JSON 檔案（例如 `vocab-backup-2026-07-23.json`）。
2. 把這個檔案存到雲端硬碟（Google Drive、iCloud 等等），或是傳給自己（例如傳到自己的 Line、Email）保存起來。
3. 之後如果換了新手機、或是進度不見了，重新安裝 App 後，點「⬆️ 匯入備份」，選回你存的那個 JSON 檔案，就可以把進度救回來。

**建議**：只要你有認真在用這個 App，就每隔幾天匯出備份一次，尤其是用 iPhone 的話更要記得，不然辛苦累積的進度可能會被系統清掉。
